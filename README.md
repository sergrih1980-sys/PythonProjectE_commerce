# Система управления товарами и категориями

Простая система для работы с товарами и их категоризацией. Реализует базовые классы для хранения информации о продуктах и группирования их по категориям.

##  Возможности

* Создание товаров с указанием названия, цены, количества и описания
* Группировка товаров по категориям
* Автоматический подсчёт количества созданных товаров и категорий
* Управление запасами через атрибуты товаров

## Классы и их функциональность

###  Класс `Product`
Представляет отдельный товар в системе.

**Атрибуты:**
* `name` (str) — название товара;
* `description` (str) — описание товара;
* `price` (float) — цена товара;
* `quantity` (int) — количество на складе;
* `product_count` (class attribute, int) — общее количество созданных товаров (статический счётчик).

**Инициализация:**
```python```
`Product`(name: str, price: float, quantity: int, description: str)

###  Класс `Category`

 Представляет категорию товаров.

**Атрибуты:**

* `name` (str) — название категории;

* `description` (str) — описание категории;

* `products` (list) — список товаров в категории;

* `category_count`(class attribute, int) — общее количество созданных категорий (статический счётчик);

* `product_count` (class attribute, int) — дублирующий счётчик товаров (см. раздел «Особенности реализации»).

**Инициализация:**

 ```python```
`Category`(name: str, description: str, products: list)

### Особенности реализации

**Счётчики объектов:**

* `Product.product_count` увеличивается при создании каждого товара;

* `Category.category_count` увеличивается при создании каждой категории;

* `Category.product_count` также увеличивается при создании категории — это может приводить к неточностям в подсчётах (см. раздел «Проблемы и улучшения»).

Дублирование счётчика товаров в классе `Category` может вызвать расхождение данных, если товары создаются вне категорий.

### Пример использования

```python```
# Создаём товары
`tv = Product("55\" QLED 4K", 123000.0, 7, "Фоновая подсветка")`
`phone = Product("Смартфон X", 50000.0, 15, "8 ГБ ОЗУ, 256 ГБ памяти")`

# Создаём категорию и добавляем товары
`electronics` = `Category`(
    "Электроника",
    "Современные электронные устройства",
    [tv, phone]
)

# Проверяем счётчики
print(f"Всего товаров: {Product.product_count}")         # Вывод: 2
print(f"Всего категорий: {Category.category_count}")     # Вывод: 1
print(f"Счётчик в категории: {Category.product_count}")  # Вывод: 1

# Система управления товарами
Программный модуль для работы с категориями товаров и различными типами продуктов, включая смартфоны и газонную траву. Реализована строгая типизация операций сложения и валидация данных.

## Функциональность
**Система предоставляет:**

* базовую модель товара `(Product)`;

* специализированные типы товаров: смартфоны `(Smartphone)` и газонная трава `(LawnGrass)`;

* механизм категоризации товаров `(Category)`;

* контроль типов при операциях сложения товаров;

* валидацию данных (например, проверку цены).

## Классы и их назначение
* `Product`(базовый класс)
* Базовый класс для всех товаров. Содержит общие атрибуты и методы.

**Атрибуты:**

* `name` — название товара;

* `description` — описание товара;

* `price` — цена (с валидацией: не может быть ≤ 0);

* `quantity` — количество на складе.

**Методы:**

* `__str__()` — строковое представление товара;

* `get_total_value()` — расчёт общей стоимости всех единиц товара на складе;

* `__add__()` — сложение стоимости двух товаров (только для объектов класса Product);

* `new_product()` — фабричный метод для создания товара из словаря;

* геттер и сеттер для `price` с проверкой корректности значения.

`Smartphone` (наследник `Product`)
Класс для смартфонов с дополнительными характеристиками.

**Дополнительные атрибуты:**

* `efficiency`— производительность;

* `model` —  модель устройства;

* `memory` — объём встроенной памяти;

* `color` — цвет.

**Особенность:** метод `__add__()` позволяет складывать только объекты класса Smartphone.

`LawnGrass` (наследник Product)
Класс для газонной травы с отраслевыми характеристиками.

**Дополнительные атрибуты:**

* `country` — страна‑производитель;

* `germination_period` — срок прорастания;

* `color` — цвет травы.

**Особенность:** метод `__add__()`позволяет складывать только объекты класса LawnGrass.

`Category`
Класс для группировки товаров в категории.

**Атрибуты:**

* `name` — название категории;

* `description`— описание категории;

* `products` — список товаров в категории (внутренний атрибут __products);

* `category_count` — глобальный счётчик категорий;

* `product_count` — глобальный счётчик товаров во всех категориях.

**Методы:**

* `__str__()` — строковое представление категории с общим количеством товаров;

* `get_product_count()` — возвращает количество товаров в категории;

* `add_product()` — добавляет товар в категорию (только экземпляры Product или его наследников);

* свойство `products` — возвращает список строк с информацией о товарах.

 ##  BaseProduct (Абстрактный базовый класс)
Определяет контракт для всех товаров в системе.

**Ключевые особенности:**

* абстрактный метод `new_base_product` — гарантирует реализацию фабричного метода в подклассах;

* автоматическое логирование создания объектов через `__repr__`;

* унифицированный формат вывода информации о товаре.
